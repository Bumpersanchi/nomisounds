Privacy Policy

Nomi Sounds Uploader · last updated 7 October 2026

Who uses this app

Nomi Sounds Uploader is a personal tool. Its only user is the owner of the YouTube channels Nomi Sounds and The Quiet North. It is not available to the public.

What data it accesses

With the owner's permission, the app uses the YouTube Data API and YouTube Analytics API to upload and schedule videos, edit titles and descriptions, post comments, manage playlists and read statistics of the owner's own channels. It does not access any other user's data.

How data is stored

Access tokens are stored privately on the owner's computer and in the owner's private database, only to run scheduled uploads and reports. Channel statistics are used only to produce private reports for the owner. No data is sold, shared with third parties or used for advertising.

Google API Services

The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. This app uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions. Stored tokens are then deleted.
